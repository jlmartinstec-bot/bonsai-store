## Escopo Atual do Projeto – Bonsai Store
A Bonsai Store é uma pequena aplicação web que permite visualizar, cadastrar e gerenciar bonsais disponíveis para venda. A solução inclui:

- Catálogo simples de bonsais
- Página inicial com apresentação da loja
- CRUD básico (Criar, Ler, Atualizar, Excluir)
- Design minimalista e funcional
- Backend em Python + Flask
- Banco de dados simples (SQLite)
- Interface clara seguindo princípios de UX
- Protótipo navegável da interface

## Limitações da Versão Atual (MVP)
- Não possui carrinho de compras completo
- Não possui login de usuário
- Não possui integração com meios de pagamento
- Foco exclusivo em CRUD de produtos (bonsais)

## Justificativa da Revisão
Os ajustes foram feitos para:
- Reduzir a complexidade do projeto
- Garantir a entrega dentro do prazo
- Facilitar testes e validação por colegas
- Adotar uma solução realista e viável
